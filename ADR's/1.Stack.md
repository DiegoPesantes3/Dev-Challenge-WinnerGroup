# ADR 1: Technology Stack Selection


## Decision
We have decided to use the following technology stack for the MVP:

### Frontend
* **React:** For building a dynamic and responsive user interface component tree.
* **Vite:** As the build tool and development server for fast HMR (Hot Module Replacement) and optimized builds.
* **Tailwind CSS:** For rapid, utility-first styling to create a modern, minimalist, and visually appealing interface.

### Backend
* **Node.js & Express:** For a lightweight, fast, and unopinionated server to handle incoming requests.
* **Multer:** For handling `multipart/form-data`. Specifically, using `memoryStorage()` to process images in RAM without relying on a persistent disk (making it serverless-ready).
* **LangChain & Zod:** For orchestrating the AI workflow and enforcing structured JSON outputs from the LLM.

### AI / External Services
* **Google Gemini 3.1 Flash Lite:** Accessed via `@langchain/google-genai` for its fast image analysis capabilities and cost-effectiveness during the MVP phase.
