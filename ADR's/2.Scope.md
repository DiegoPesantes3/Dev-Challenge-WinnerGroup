# ADR 3: MVP Project Scope

## Status
Accepted

## Context
This project is being developed for the Dev Challenge 2026 by PUCE TEC. The overarching goal is to reduce the impact of fake news in the Hispanic gaming community. To ensure a timely delivery of a functional prototype, we must strictly define the boundaries of the Minimum Viable Product (MVP).

## Decision
We have defined the scope of the MVP as follows:

### In Scope (MVP)
* **Image Upload Interface:** A minimalist UI allowing users to drag-and-drop images or paste image URLs.
* **AI Analysis:** Verification of the image to check if it's real or fake (edited, AI-generated, baseless rumor) specifically within the context of video games, using IGN as the primary reference constraint.
* **Traffic Light Report (Semáforo):** Providing a clear, color-coded result:
  * **Red:** Fake News
  * **Yellow:** Doubtful / Unconfirmed
  * **Green:** Real / Verified
* **Stateless Processing:** Images are analyzed in real-time and discarded immediately.

### Out of Scope (Deferred for Future Versions)
* **Database Integration:** No PostgreSQL or TypeORM will be used in the MVP.
* **History & Analytics:** Users will not be able to see a history of previously analyzed images.
* **Persistent File Storage:** Vercel Blob or local disk storage for images is excluded.
* **User Accounts:** No authentication or authorization systems.

## Consequences
* **Positive:** Drastically reduces development time and complexity, allowing the team to focus entirely on the core value proposition (AI verification).
* **Negative:** The system lacks persistence, which might be a requirement for a full production launch but is acceptable for a Dev Challenge prototype demonstration.
